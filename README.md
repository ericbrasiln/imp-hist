# Imprensa e História — apresentação

Apresentação em Quarto/RevealJS para o encontro do grupo de pesquisa **Imprensa e História**, em 20 de outubro de 2026.

## Renderização

```bash
quarto render index.qmd
```

O resultado principal é `index.html`.

## Estrutura

- `index.qmd`: fonte da apresentação e notas do apresentador.
- `styles.css`: identidade visual.
- `imgs/`: imagens herdadas do repositório de referência para uso posterior.
- `sources/`: fontes e registros de pesquisa a acrescentar.

A versão atual tem 33 slides. Ela incorpora o percurso da apresentação `slacsc` e mantém a seção sobre inteligência artificial, agentes de IA, APIs e o projeto Impresso.

## Repositório de referência

A estrutura visual e técnica inicial segue o repositório [`slacsc`](https://github.com/ericbrasiln/slacsc).
